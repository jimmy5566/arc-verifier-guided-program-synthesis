# Director scientific review guidance

For a proposed targeted-training protocol, distinguish capabilities needing repair from capabilities that are already strong but need protection from forgetting. Record explicit train-only preservation coverage for each strong baseline capability. Missing preservation coverage is a scientific risk to assess, not a provenance gate or a reason to repeat routine reviews.

If a strong capability later regresses, state the protection-coverage hypothesis as non-causal unless a prospective one-factor intervention tests it. A successor protocol may add train-only replay for that capability only as its explicitly controlled factor.
