# Graduate proposal evidence freeze: runtime intervention

This directory freezes the preliminary evidence for the working proposal:

> **Responsibility-Aware Runtime Intervention for Interactive LLM Agents**

It is an archival research snapshot, not a change to ARC2 competition code.
Only compact, derived CSV/JSON results and selected figures are copied here.
Large candidate pools, frozen predictions, and raw ARC artifacts are referenced
in `DATA_AND_ARTIFACT_LINKS.md` rather than duplicated.

Start with:

- `RESEARCH_STATUS.md` — frozen conclusion and scope boundary;
- `EVIDENCE_INDEX.md` — stage-by-stage evidence chain;
- `proposal_support/PRELIMINARY_RESULTS.md` — proposal-facing numbers;
- `proposal_support/LIMITATIONS.md` — claims that this archive does not make;
- `DATA_AND_ARTIFACT_LINKS.md` — source locations, copy/reference status, and
  SHA-256 provenance.

All reported simulator results are controlled preliminary evidence. They are
not interactive-LLM benchmark results and must not be represented as such.
