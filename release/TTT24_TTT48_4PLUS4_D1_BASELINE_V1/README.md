# TTT24_TTT48_4PLUS4_D1_BASELINE_V1

This directory is a review snapshot of the fixed Eval60 development baseline,
not a competition release and not a claim about hidden leaderboard accuracy.

The frozen portfolio has eight greedy slots per test output:

- TTT24: `flip_lr`, `flip_ud`, `transpose`, `anti_transpose`
- TTT48: `identity`, `rot90`, `flip_ud`, `anti_transpose`

`D1` preserves source-local B-SUPPORT, support aggregation, primary B-RRF,
and the historical representative ordering.  It uses source-local
original-likelihood reciprocal rank only for *exact numerical* B-RRF ties:

`(-B_RRF, -L_RRF, historical_representative, grid_key)`.

The CPU replay target is Top-1 `20/89`, Top-2 `28/89`, and pool oracle
`30/89`.  This is retrospective development evidence only.

`RELEASE_STATUS.json` and `RELEASE_STATUS.md` are generated by
`scripts/audit_d1_baseline_release.py`.  A `RELEASE_BLOCKED` result is an
intentional truthful review outcome: it does not authorize a Kaggle run or a
competition submission.
